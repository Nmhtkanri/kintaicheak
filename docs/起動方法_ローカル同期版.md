# 勤怠チェッカー 起動方法（ローカル同期版）/ Kintai Checker – How to Launch (Local-Sync Edition)

2026-07-02 より、起動のしくみが新しくなりました。**操作はいままでと同じ**ですが、初回だけ準備が必要です。
Starting 2026-07-02, the launcher works in a new way. **Your daily operation stays the same**, but a one-time setup is needed.

---

## 初回だけやること / One-Time Setup

1. エクスプローラーで次のフォルダを開く / Open this folder in File Explorer:
   `Z:\勤怠チェックシステム\kintai-checker`
2. `起動.bat`（種類: Windows バッチ ファイル）を **右クリック → 「送る」→「デスクトップ（ショートカットを作成）」**
   Right-click `起動.bat` → **Send to → Desktop (create shortcut)**
3. 以後はデスクトップのショートカットをダブルクリックするだけ
   From now on, just double-click the desktop shortcut.

> ⚠️ `起動.bat` 本体をデスクトップに**コピーしないでください**（必ず「ショートカット」で）。
> ⚠️ Do **not copy** the `起動.bat` file itself to your desktop — always use a **shortcut**.

## 毎回の使い方 / Daily Use

- ショートカットをダブルクリック → 黒い画面が出て、少し待つとブラウザが自動で開きます。
  Double-click the shortcut → a black console window appears, and your browser opens automatically.
- 使い終わったら黒い画面を閉じてください（それでサーバーが止まります）。
  When you finish, close the black window (this stops the app).

## 知っておいてほしいこと / Good to Know

- **いちばん最初の起動だけ数分かかります**（約200MBをあなたのPCにコピーするため）。2回目からは今までよりずっと速く起動します。
  **The very first launch takes a few minutes** (about 200 MB is copied to your PC). After that, it starts much faster than before.
- アプリが更新された直後の起動も、更新分のコピーで少し時間がかかることがあります。
  Right after the app is updated, the next launch may also take a little longer while the update is copied.
- 5人が同時に使っても大丈夫です（それぞれのPCで独立して動きます）。
  All five of us can use it at the same time (it runs independently on each PC).
- すでに起動中にもう一度ダブルクリックした場合は、ブラウザが開くだけです（二重起動はしません）。
  If you double-click while it is already running, it just opens the browser again (no duplicate launch).

## 困ったとき / Troubleshooting

- ブラウザが開かない → 手動で `http://localhost:5000` を開いてみてください。
  Browser does not open → try opening `http://localhost:5000` manually.
- 「[WARN] Could not update the local copy」と出た → そのまま共有ドライブ版で起動します（遅いだけで使えます）。続くようなら管理者（谷津）へ連絡してください。
  If you see "[WARN] Could not update the local copy", the app still starts from the shared drive (slower but usable). If it keeps happening, contact the administrator (Yatsu).

### 管理者向けメモ / Admin Notes（谷津用）

- 更新手順: ソース修正 → `kintai-exe-builder` で再ビルド → NASの `dist\KintaiChecker` を差し替え。**それだけで全員に自動反映**（各PCは次回起動時に `KintaiChecker.exe` と `.env` のタイムスタンプ差分を検知して同期）。
- `.env`（APIキー等）だけの変更も再ビルド不要で自動配布される（起動batが `.env` も監視対象にしているため）。
- 各PCのローカル配置先: `%LOCALAPPDATA%\KintaiChecker`（この下の `uploads/` `outputs/` は各ユーザー専用。同期で消えない設計）。
- 旧起動bat のバックアップ: `docs\起動_旧_NAS直接起動.bat.bak`
