# 経費統合一覧表 移植 P1a — 全行一致 認証手順（フレッシュ並行実行）

現行マクロ（`経費利用履歴 RevN.xlsm`）と Python 実装（`services/keihi_summary.py`）を
**同じ生ファイルに通して**、生成される「経費統合一覧表」が全行・全列一致するか確認する。

> ✅ **2026-07-16 認証達成**: 谷津さんが標準取込で出力した `確認用統合一覧表.xlsx`（2444行）に対し、
> 同じ4生ファイルからの Python 出力が **34列・全2444行 完全一致（差分0）**。`cert_keihi_integration.py` で `[OK] 合格`。

> なぜ過去の Rev5 と突合しないか: 既存の `経費利用履歴 Rev5.csv` は、対話的作業（複数回paste・
> 別抽出の混在・SAP説明列の手修正・営業部freeeの別経路取込）が積み重なった歴史的成果物で、
> どの単一の生ファイル群からもバイト単位で再現できないことが判明したため（2026-07-16 調査）。
> 「1組の生ファイル → マクロ出力 と Python出力 を突合」する方式なら履歴ノイズが入らない。

---

## 手順

### 1. 生ファイルを1組そろえる（4ソース）
`Y:\給与明細\R8年\7月\経費確認精査データ\P1a検証セット\` などに、その月の生ファイルを置く:

| ソース | ファイル | 注意 |
|---|---|---|
| jinjer | `*仕訳データ.csv` | その月の全社員分（対象者が欠けていないこと。例: 加藤 英人さんの行が入っているか） |
| e-staffing | `勤怠データダウンロード_立替金_*.csv` | |
| SAP | `経費月次出力_API連携用*.csv` | **超集合 (4) ではなく、その月に実際に取り込む重複除外済ファイル**（Rev5 は180行の (5) が正だった） |
| freee | `経費精算-*.csv` | |

### 2. 現行マクロを回して「経費統合一覧表」を出力（正解を作る）
1. `経費利用履歴 RevN.xlsm` を開き、いつも通り4ソースを貼り付け → `Append_全部_Freee含む_一括処理` を実行。
   - **重複削除は行わない**（現行どおり無効。Rev5準拠）。
   - 営業部freeeなど**追加の別paste はしない**（標準の1回取込のみにする＝再現可能にするため）。
2. 「経費統合一覧表」シートを **CSVで書き出す**（例: `統合一覧表_マクロ出力_YYYYMM.csv`、文字コードは任意）。
3. この時 **手順1で貼り付けたのと同じ4生ファイル**を保存しておく（貼付後に再エクスポート／編集しないこと）。

### 3. Python 実装で認証
リポジトリ直下で（`route_check` 不要・オフライン可。社員番号ロスターは正解CSVとjinjerから構築）:

```bat
python cert_keihi_integration.py ^
  --jinjer    "Y:\...\P1a検証セット\XXXX仕訳データ.csv" ^
  --estaffing "Y:\...\P1a検証セット\勤怠データダウンロード_立替金_XXXX.csv" ^
  --sap       "Y:\...\P1a検証セット\経費月次出力_API連携用 (N).csv" ^
  --freee     "Y:\...\P1a検証セット\経費精算-XXXX.csv" ^
  --expected  "Y:\...\P1a検証セット\統合一覧表_マクロ出力_YYYYMM.csv"
```

### 4. 判定
- `[OK] 合格: 全行・全列一致（差分0）` が出れば **P1a 合格**。
- 差分が出たら「未生成（正解のみ）」「余剰（生成のみ）」のサンプルを見て原因を切り分ける
  （社員番号未照合・日付書式・分類列など）。ロジック起因の差分ならこちらで修正する。

## 認証時に判明し、コード側で対応済みの挙動（Excel取込の再現）
差分0 に到達する過程で、現行マクロ＝Excel経由の以下の癖を Python 側で再現した（`services/keihi_summary.py`）:
- **SAP 説明(F) の日付化**: `Workbooks.OpenText` が「6月5日」等の説明を日付シリアル化するため、
  `excel_coerce_jp_date` で 費用エントリ日の年を使い "2026/06/05" に変換して備考(明細)へ入れる。
- **原文保持**: freee 内容・SAP 説明の改行や前後空白は strip/改行置換せずそのまま（マクロ CStr 相当）。
- **freee 本社経費の 利用日(F) = 日付**: 標準の `Append_本社経費` は利用日を入れる
  （旧 Rev5 で空だったのは営業部の別経路取込という特殊事情で、標準経路では入るのが正）。
- jinjer の Excel 型変換（`00000236→236`・`2026/06/01→2026/6/1`）は `excel_coerce` で既に再現済み。

## 参考: 旧 Rev5 が再現不能だった理由（2026-07-16 調査。フレッシュ実行では解消）
- jinjer: 旧提供CSVに 加藤 英人(2024050) の11行が欠落。
- SAP: フォルダの旧SAPが超集合 (4)（Rev5 は 180行）＋夜間当番説明の別エクスポート。
- freee: 営業部分が別経路（仕訳区分空＋"本社経費"マーカー行）で混在。
→ いずれも「同一マクロ実行の同一生ファイル」を両者に通すフレッシュ方式で解消し、差分0 を達成。
