# review-notes — system-reviewer に渡す前提メモ

`~/.claude/agents/system-reviewer.md`（ユーザー階層の共通レビュー担当）に、このシステム固有の
業務ルール・既知の落とし穴・宿題を読ませるためのメモ置き場。レビュー担当はコードから読める
ことしか判断できないので、コードに書かれていない前提はここに文章で置く。

## 使い方

- レビューを頼むとき、`_common.md` と対象モードのメモのパスを必ず渡す。
- 1 モード 1 ファイル。ファイル名はルート名の接頭辞に合わせる（`keiri.md` なら `/keiri_*`）。
- 事故・宿題・ルールを見つけたら、その場でここに追記する（日付付き）。記憶ファイルや README に
  あってもここに無ければレビュー担当は知らない。
- 新しいシステムをハブに統合したら、そのモードのメモを 1 本足す。

## 各メモの構成

1. 入口（ルートと主な services）
2. 入力（何をどこから読むか）
3. 出力と不可逆な処理（何を書き、何が戻せないか）
4. 業務ルール（コードがこれに反したら重大）
5. 既知の落とし穴（過去の事故。日付付き）
6. 宿題・未確認の前提

## 初回作成時の注意

2026-09-10 に作業記憶から転記して作成した。日付の付いた項目は当時の状態であり、コードと
食い違ったら**コードの現状を確かめてからメモを直す**。
