# イレギュラー経費 一括取込テンプレート（経理モード）

経費チェックモードの「イレギュラー経費 → まとめて入れる場合のファイル指定」に渡すファイルの
定型テンプレートです。読み取り仕様は `services/keihi_payroll_import.py` の `load_irregular_file()`。

## ファイル

| ファイル | 形式 | おすすめ |
|---|---|---|
| `イレギュラー経費_ロング形式_テンプレート.xlsx` | 社員番号 / 項目 / 金額 の3列 | ★これを使う |
| `イレギュラー経費_ロング形式_テンプレート.csv` | 同上（Shift-JIS） | CSVがよければ |
| `イレギュラー経費_ワイド形式_テンプレート.xlsx` | 社員番号 + 項目名の列 | 一覧で見たいとき |

毎月、テンプレートを**コピーしてから**記入してください（例: `イレギュラー経費_202608.xlsx`）。

## 書ける項目（この5つ以外はエラー）

```
定常外業務対応手当 / その他手当 / 現物支給 / 支給過不足調整 / 社保調整
```

非課税通勤費・立替金・その他・夜間当番手当は経費データから自動計算されるので、ここには書けません。

## ルール

- **社員番号は数字のみ**。先頭ゼロは付けても落ちます（`02026013` → `2026013`）。
- 5 / 6 / 9 始まりは給与計算対象外なのでエラーになります（派遣・テスト用）。
- **金額はマイナス可**（過払いの戻し、社保調整など）。
- 同じ社員・同じ項目を複数行書くと**合算**されます。
- 金額 0 の行は無視されます（書いても結果は変わりません）。
- ワイド形式で**該当しない項目は空欄のままでOK**（0を入れても同じ）。
- 先頭が `#` の行は取り込まれません（メモ・記入例に使えます）。
- 氏名の列は入れても入れなくてもOK（照合には使いません。社員番号だけで判定します）。

## 入れた金額が経理モード（freee給与仕訳）でどうなるか

**手入力は要りません。5項目とも品目マッピングマスタに定義済みなので自動で仕訳になります。**
経理モードが経費ブック（経費利用履歴 RevN.xlsm）と突き合わせるのは「**その他**」だけで、
ここの5項目は jinjer給与明細から直接読まれます。
（経費チェックモードが出す `経費統合一覧表.xlsx` は経理モードの入力ではありません）

| 項目 | jinjer項目 | freeeでの計上先 |
|---|---|---|
| 定常外業務対応手当 | allowance19 | 給料手当／人件費（区分）に**合算**（独立行にならない） |
| その他手当 | allowance21 | 同上 |
| 支給過不足調整 | allowance54 | 同上 |
| 現物支給 | allowance53 | 給料手当／人件費（区分）＋**仮払金のマイナス行**を自動生成 |
| 社保調整 | deduction4 | 預り金／健保・介護・厚年・子育て支援金へ**按分**（端数が出たら厚年1本） |

上3つは独立行にならず、その人の人件費1行に溶けます（備考も付きません）。
金額は正しく入りますが、freee上で「これは定常外業務対応手当」とは見えない形です。

⚠️ **「その他手当」を入れた月は、要確認mdの「新規使用検知」を必ず見てください。**
jinjer には「その他手当」というラベルの項目が **allowance20（家賃手当・対象外）** と
**allowance21（計上する）** の2つあります。どちらに着地するかは jinjer 側のテンプレート設定
（経費APIインポート用）が決めており、チェッカー側は列名でPOSTしているだけなので検証できません。
allowance20 に入ると**その月の仕訳から落ちて**新規使用検知に出ます（調整手当の15→12移設と同じ網）。

## エラーで止まるときのチェックポイント

1. **見出しの名前が違う**（いちばん多い）
   → 「支給過不足調整」を「過不足調整」、「社保調整」を「社会保険調整」などにすると
   項目として認識されません。上の5つと**1文字も違わない**名前にしてください。
2. **1行目が見出しになっていない**
   → タイトル行や空行を1行目に入れないでください。1行目＝見出し、2行目以降＝データ。
3. **社員番号が数字になっていない**
   → 「2026013（田中）」のようにメモを混ぜるとエラーです。氏名は別の列へ。
4. **CSVの文字コード**
   → Shift-JIS（`CSV UTF-8` でも可）。迷ったら xlsx のまま渡すのが確実です。
5. **フォルダを指定した**
   → ファイル（.xlsx / .csv）のフルパスを指定してください。

エラーメッセージには何行目のどの項目かが出るので、そこを直せば通ります。
