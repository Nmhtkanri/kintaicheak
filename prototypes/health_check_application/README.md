# 健康診断申込テスト版

Google Workspace上の専用申込画面を作る前に、操作感とデータの流れを確認するためのローカルプロトタイプです。

## この版でできること

- 架空の従業員3名から個別申込画面を開く
- 社員番号・氏名・社用メールを固定表示する
- 前年度と同じ内容、または変更内容を選択する
- 変更時は指定された健診機関からプルダウン選択する
- 通常の健診機関では健診オプションを複数選択する
- 「その他」の場合だけ医療機関名と健診予定日を任意入力する
- 被扶養者を含める場合だけ妻・夫と氏名を入力する
- 備考を入力する
- 1つの個別URLからの重複申込を止める
- 管理者用一覧で受付内容を確認する
- テスト回答をリセットする

## 安全上の制限

- 実在する社員番号・氏名・メールアドレスは含みません。
- 回答はメモリ上だけに保持し、サーバーを終了すると消えます。
- 127.0.0.1 にだけ公開するため、同じPC以外からは接続できません。
- メール、Googleスプレッドシート、jinjerには接続しません。
- Operation Hub本体および配布exeには組み込まれていません。

## 起動方法

start_test.bat をダブルクリックします。通常はブラウザが自動的に開きます。

手動の場合は、このフォルダで「python -X utf8 preview_server.py」を実行します。起動後のURLは http://127.0.0.1:8765/ です。終了するときは、起動した黒い画面で Ctrl+C を押します。

## Google Workspace版へ進める場合

画面と項目を確定した後、同じ流れをApps Script Webアプリへ移します。本番化前に、Workspace管理設定、個別キーの期限・再発行、管理者権限、Googleスプレッドシートの共有範囲、メール文面、jinjer送信前のdry-runを別途確認します。
