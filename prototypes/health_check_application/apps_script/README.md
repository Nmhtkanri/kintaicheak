# Google Apps Script 試験版

3名限定の健康診断申込を、Googleアカウントなしでも開ける個別URLとして配布する試験版です。

- 個人情報と個別トークンは、このリポジトリには保存しません。
- `Code.gs` の `PILOT_SPREADSHEET_ID` と `PILOT_TARGETS` は、管理者専用Apps Scriptプロジェクト側だけで設定します。
- Webアプリは「実行ユーザー: 自分」「アクセスできるユーザー: 全員」として試験公開します。
- 回答シートは管理者のみが閲覧し、従業員とは共有しません。
- 有効な個別URLの初回表示時に「初回アクセス日時」、送信完了時に「回答日時」を別々に記録します。
- 初回アクセスはメールのセキュリティ検査による自動確認でも記録される可能性があるため、本人閲覧の参考情報として扱います。IPアドレスや端末情報は保存しません。
- 試験版はjinjerを更新しません。
- `setupPilot()` を1回実行して3シートを初期化した後、Webアプリをデプロイします。

前年度情報を設定していない対象者は「前年度と同じ」を選べず、変更入力だけを試せます。
