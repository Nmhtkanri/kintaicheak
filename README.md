# kintai-checker

勤怠時間の突合システム。jinjer の勤怠 CSV と各部署の勤務表（Excel/PDF/画像）を突き合わせ、
**差分があるレコードを自動で検出**して Excel レポートを出力する Flask Web アプリ。

## ✨ 主な機能

| 機能 | 内容 |
|---|---|
| 勤怠突合 | jinjer CSV と勤務表ファイル（複数可）を突合、差分を OK / NG / 要確認 / データ欠損 で判定 |
| 多形式対応 | 勤務表は xlsx / xls / pdf / png / jpg / jpeg に対応（Claude Vision で OCR）|
| 未提出者検出 | jinjer に居るのに勤務表が無い人を一覧化 |
| **シフト記号対応** 🆕 | `B = 12:30-21:00`、`● = 夜勤`、`明 = 休` のような **記号式シフト表を自動で時刻化**（凡例レビュー UI 付き）|
| **新規雛形 CSV 生成** 🆕 | jinjer 既存雛形にマッチしない記号は **インポート用 CSV を自動生成**。人間はそのまま jinjer にアップするだけ |
| **24:00跨ぎ統合** 🆕 | `4 (16:30-24:00) + a (24:00-翌09:00)` を `16:30-翌09:00` の 1 レコードに統合 |

## 🔄 処理フロー

### A. 直接時刻が書かれた勤務表（既存）

```
[jinjer CSV]  +  [勤務表（時刻直書き）]
   ↓                  ↓
   └──┬───────────────┘
      ▼
   突合 → Excel 出力
```

### B. シフト記号で書かれた勤務表 🆕

```
[jinjer CSV] + [勤務表（記号式）]
   ↓               ↓
   ↓          Claude API でモード判定
   ↓          → "code" モード検出
   ↓               ↓
   ↓          凡例＋シフト表 抽出
   ↓               ↓
   ↓          【凡例レビューUI】← 人間が確認・修正
   ↓               ↓
   ↓          記号 → 時刻 解決（24:00跨ぎ統合含む）
   └──┬───────────┘
      ▼
   突合 → Excel 出力
   ＋ jinjer 雛形にない記号があれば「新規雛形 CSV」も同時生成
```

## 🆕 シフト記号対応の仕組み

### 1. 自動モード判定

Claude API が勤務表を見て、以下を自動判定します：

- `direct` モード：時刻が直接書かれている（例: 9:00-17:30）
- `code` モード：記号式（例: B, ●, A/B/明, 2/4/a）+ 同じファイルに凡例あり

### 2. 凡例レビュー UI

`code` モードと判定された場合、抽出された凡例が **編集可能なテーブル** で表示されます。

| 記号 | 種別 | 出勤 | 退勤 | 休憩(分) | 休? | jinjer 雛形 |
|---|---|---|---|---|---|---|
| B | B勤 | 12:30 | 21:00 | 60 | □ | 新規雛形候補 |
| ● | 夜勤 | 16:30 | 25:00 | 60 | □ | No 38 夜帯シフト |
| 明 | 明け休 | — | — | — | ☑ | — |
| 振 | 振休 | — | — | — | ☑ | — |

- セルをクリックで直接編集できます
- 「休？」にチェックを入れるとその記号は **休扱い**
- jinjer 既存雛形にマッチした記号は **緑タグ**、しないものは **黄色タグ**で表示
- 「✅ この凡例で実行」を押すと突合へ進みます

### 3. 24:00 跨ぎ統合

連続する 2 日のシフトが 24:00 で繋がっている場合、1 レコードに統合されます。

```
田村さん:
  4日: 4 = 16:30-24:00
  5日: a = 24:00-翌09:00
   ↓ 統合
  4日: 16:30-翌09:00（実態は 33:00）
```

これは jinjer 側の打刻記録（1 シフト = 1 レコード）と整合します。

### 4. 新規雛形 CSV 生成

jinjer の既存雛形（`Z:\jinjer移行\カレンダー\スケジュール雛形一覧_*.csv`）と照合し、
マッチしない記号があれば **インポート用 CSV** を自動生成します。

```csv
No,勤怠スケジュール名称,略称(3文字以内),勤怠スケジュール名ID,予定区分,休日ID,出勤時刻(0:00~47:59),退勤時刻(0:00~47:59),...
56,B勤,B,B,9998,1,12:30:00,21:00:00,...
```

このまま jinjer にアップロードできます。
